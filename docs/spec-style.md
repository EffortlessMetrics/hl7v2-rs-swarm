# Spec style and source-of-truth model

This repository keeps durable spec rails in `.hl7v2-rs-swarm-spec/`.

- `docs/` explains process and contributor guidance.
- `policy/` contains live enforcement ledgers.
- `.codex/`, `.spec/`, `.claude/`, and `.jules/` are external/tool-specific state.

Keep *why*, *what*, *decision*, *how*, *proof*, and *closeout* in separate artifacts.
