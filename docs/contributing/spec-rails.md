# Contributing to spec rails

Use `.hl7v2-rs-swarm-spec/` for durable artifacts:

1. Proposal (`proposals/`) for motivation and alternatives.
2. Spec (`specs/`) for behavior and evidence requirements.
3. ADR (`adr/`) for durable architecture decisions.
4. Lane tracker (`lanes/<id>/tracker.toml`) for durable execution state.
5. Implementation plan for PR-sized slices.
6. Closeout for landed proof and remaining work.

Do not store durable rails in `.codex/`, `.spec/`, `.claude/`, or `.jules/`.
